## kmeshctl mcp serve

Run the MCP server (supports stdio and sse transport)

```bash
kmeshctl mcp serve [flags]
```

### Options

```bash
  -h, --help               help for serve
      --transport string   Transport protocol to use: 'stdio' (default) or 'sse' (default "stdio")
```
