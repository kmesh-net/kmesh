## kmeshctl namespace list

List Kmesh enrolled namespaces

### Synopsis

List all namespaces that have the istio.io/dataplane-mode=Kmesh label

```bash
kmeshctl namespace list [flags]
```

### Examples

```bash
  # List all Kmesh namespaces
  kmeshctl namespace list
```

### Options

```bash
  -h, --help   help for list
```
