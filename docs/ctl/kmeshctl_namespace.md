## kmeshctl namespace

Manage Kmesh namespaces

### Synopsis

A group of commands used to manage Kmesh namespaces

```bash
kmeshctl namespace [flags]
```

### Examples

```bash
  # List all namespaces enrolled in Kmesh
  kmeshctl namespace list
```

### Options

```bash
  -h, --help   help for namespace
```
